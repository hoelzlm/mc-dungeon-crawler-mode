**What to build:** Using a **Stairwell Aid** (Seeker's Draught, Echo Chime, Revealing Lantern, Fragment Map) paints a rough area on the user's **Floor Map** that contains a **Stairwell**, never an exact spot. The **Stairwell Aid** entry in `GLOSSARY.md` gets a line saying an Aid paints an area on the **Floor Map**.
