# 02: The Host voice

**What to build:** The **System** (**The Host**) speaks: pre-written lines loaded from data files appear as an on-screen banner with a sound cue and are also written to chat. Lines come from a source behind an interface so an LLM source can be added later.

**Blocked by:** 01

**Status:** ready-for-agent
